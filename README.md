## Technology

Next.js, React, TypeScript.

## Get started

```sh
git clone https://github.com/Up-to-code/enhanced-ecommerce.git
cd enhanced-ecommerce
```

Requires Bun and bun.

```sh
bun install
bun run dev
```

## Available commands

| Command | Purpose |
| --- | --- |
| `bun run dev` | Development server |
| `bun run start` | Start the configured application |
| `bun run build` | Build the project |
| `bun run lint` | Check lint rules |
